01 · Featured project

Used Car Decision Support System

Turning buyer preferences into ranked, explainable choices.

A Tableau prototype designed to move beyond static reporting. Instead of showing one fixed answer, the dashboard lets a buyer change priorities and immediately see which vehicle options fit best.

The decision problem

Price alone does not define a good car.

A buyer needs to balance budget, age, efficiency, ownership history, accident exposure, maintenance and insurance. The challenge was to make those trade-offs visible without hiding the logic inside a black box.

My contribution

I designed the interactive recommendation experience.

This was a group project. My individual work focused on the parameter-driven scoring model, recommendation logic, ranked vehicle view and score-distribution dashboard.

02 · Model design

A recommendation model the user can understand and control.

The model uses an intentionally transparent rule-based structure. Each preference has a clear effect, which makes the dashboard suitable for decision support and discussion.

Buyer controls

Five parameters let users define what “good value” means for their own situation.

Maximum car age15
Minimum mileage per dollar0
Maximum price$9K
Maximum owner count6
Require full service historyYES

Seven scoring dimensions

Each dimension contributes up to 20 points. The combined result is divided by 140 and converted into a score out of 100.

InsuranceValid coverage earns full credit.
Accident historyGraduated score for zero, one or multiple accidents.
Service historyResponds to the user's full-service requirement.
Car ageCompared with the selected maximum age.
Mileage valueMileage efficiency divided by price.
PriceEvaluated against the buyer's budget ceiling.
Owner countEvaluated against the maximum acceptable owners.
Recommendation Score = (7 component scores ÷ 140) × 100

04 · Design decisions

Three choices made the analysis more useful.

01 · USER FIRST

Start with the decision, not the chart.

The dashboard is structured around the buyer's constraints, so every visual element supports a concrete selection task.

02 · EXPLAINABLE

Keep recommendation logic visible.

A rule-based score is easy to audit, discuss and revise. Users can see which requirements are shaping the result.

03 · CONTEXT

Show both winners and the wider market.

The top-20 view supports selection, while the distribution prevents users from interpreting a ranking without understanding the available alternatives.

i
Responsible scope: This is a transparent decision-support prototype, not a machine-learning recommendation engine. The seven dimensions use equal maximum weights, and the vehicle label combines year, brand and engine size rather than a guaranteed unique listing ID.
